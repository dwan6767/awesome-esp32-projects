# Awesome ESP32 Projects

A curated list of interesting and advanced projects built with the ESP32 microcontroller.

## Radio and SDR Projects
- [ESPARGOS/esp-sdr](https://github.com/ESPARGOS/esp-sdr) - Turns ESP32 chips into software-defined radios using raw I/Q capture.
- [hardcoreerik/OrcSDR](https://github.com/hardcoreerik/OrcSDR) - Portable touchscreen SDR setup using M5Stack and RTL-SDR.
- [jochenhammes/esp32-sdr-trx](https://github.com/jochenhammes/esp32-sdr-trx) - Software-defined transceiver running on an ESP32-S3 board.
- [cifertech/Fennec](https://github.com/cifertech/Fennec) - Handheld AM, FM, and shortwave receiver using ESP32-S3 and SI4732.

## Drones and Aviation
- [ExpressLRS/ExpressLRS](https://github.com/ExpressLRS/ExpressLRS) - Open-source radio control link used for long-range drone telemetry.
- [espressif/esp-drone](https://github.com/espressif/esp-drone) - Official mini quadcopter flight controller firmware for ESP32 boards.
- [DroneBridge/ESP32](https://github.com/DroneBridge/ESP32) - Secure telemetry and video link over Wi-Fi and ESP-NOW.
- [batear-io/batear](https://github.com/batear-io/batear) - Acoustic drone detector that uses microphones to detect drone propeller sounds.

## Wireless Security and Networking
- [ruvnet/RuView](https://github.com/ruvnet/RuView) - Uses standard Wi-Fi signals for spatial intelligence and presence tracking.
- [justcallmekoko/ESP32Marauder](https://github.com/justcallmekoko/ESP32Marauder) - Wi-Fi and Bluetooth analysis and testing tool for ESP32.
- [EmenstaNougat/ESP32-BlueJammer](https://github.com/EmenstaNougat/ESP32-BlueJammer) - 2.4GHz signal interference testing tool.
- [meshtastic/firmware](https://github.com/meshtastic/firmware) - Off-grid encrypted mesh communication system using LoRa and ESP32.
- [cyberman54/ESP32-Paxcounter](https://github.com/cyberman54/ESP32-Paxcounter) - Counts people anonymously by monitoring Wi-Fi and Bluetooth probe requests.

## AI and Robotics
- [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) - Model Context Protocol voice chatbot client for ESP32.
- [espressif/esp-who](https://github.com/espressif/esp-who) - Face detection and recognition platform for ESP32-CAM modules.
- [makerspet/oomwoo](https://github.com/makerspet/oomwoo) - Open-source robotic vacuum cleaner firmware for microcontrollers.

## Emulators and Retro Gaming
- [ducalex/retro-go](https://github.com/ducalex/retro-go) - Retro console emulator firmware for playing classic games on ESP32 handhelds.
- [dcrespo3d/espectrum](https://github.com/dcrespo3d/espectrum) - ZX Spectrum emulator with VGA and HDMI output support.
- [bitluni/ESP32Lib](https://github.com/bitluni/ESP32Lib) - Composite video and audio generation libraries for ESP32.

## LED Lighting and Smart Home
- [wled/WLED](https://github.com/wled/WLED) - Firmware for controlling digital RGB LED strips over Wi-Fi.
- [esphome/esphome](https://github.com/esphome/esphome) - Configuration framework to integrate ESP32 boards with Home Assistant.
- [technoblogy/ulisp-esp](https://github.com/technoblogy/ulisp-esp) - Lisp programming language interpreter running directly on ESP32 hardware.
