# 🚀 Awesome Crazy & Advanced ESP32 Projects

A curated collection of the most innovative, wild, and mind-blowing projects built using the ESP32 / ESP32-S3 microcontroller family. From offensive security tools and edge AI computer vision to retro console emulators and synth instruments, this list covers the pinnacle of ESP32 maker engineering.
